SELLER STUDIO

Privacy notice

Effective October 26, 2026

Seller Studio Dashboard is a personal seller tool operated by Keith Marin. It supports development with eBay Sandbox test accounts and separately authorized read-only access to the owner’s Production seller account.

Information used

With the seller’s authorization, the local dashboard requests read-only access to inventory and orders in the environment the seller selects. It displays inventory SKUs, titles and quantities, and order IDs, dates, statuses, totals and currencies. The eBay response can contain additional order information in memory; the dashboard does not intentionally persist buyer names or addresses.

Storage and use

Application credentials are kept in a local configuration file on the owner’s computer. OAuth tokens and fetched account summaries remain in the active dashboard session’s server memory. They are not saved in the dashboard’s SQLite database. SQLite holds sample business data and locally saved listing drafts. Information is used for inventory and order reporting for the owner’s business. The application does not sell account information or publish or change eBay listings.

Photos and AI

The current photo feature previews images locally and produces labeled templates. It does not send photos or account data to OpenAI. OpenAI remains disconnected. Any future AI integration will require separate setup and an updated notice where needed.

This public website

These pages are hosted by GitHub Pages. They contain no analytics, advertising, external fonts or third-party scripts. GitHub may process request information under its own privacy statement. When used as an eBay authorization return page, the URL contains a temporary authorization code and state. Those values are sent to the hosting provider as part of the request; this page does not exchange them for tokens or intentionally store them. Never post a callback URL publicly.

Disconnecting and deletion

Use Disconnect in the dashboard to clear the active session’s tokens and fetched summaries. Revoke the application’s authorization through eBay to invalidate the grant. Locally saved demo data and drafts can be deleted by the owner from the local database. Hosting logs are managed by GitHub under its policies.

Questions

For non-sensitive questions, open an issue in the project repository. Do not include credentials, authorization codes, buyer information or private account details in public issues.
